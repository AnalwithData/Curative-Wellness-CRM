# Curative Wellness CRM

Live cloud-synced order, delivery, and dispatch CRM web app for Curative Wellness.

## Files
- `index.html` — Main CRM application (ready for GitHub Pages and Netlify).
- `netlify.toml` — Netlify static publish configuration.
- `.gitignore` — Ignores OS/editor temporary files.

## Deploy
- **Netlify:** Connect this GitHub repository in Netlify; it will publish the root directory automatically using `netlify.toml`.
- **GitHub Pages:** Go to **Settings → Pages**, select the `main` branch and `/ (root)` folder, and save.
